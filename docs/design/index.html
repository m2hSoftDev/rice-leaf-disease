Rice Leaf Disease Detection — UI Design Proposal (Revision 2)

Complete visual specification and interactive wireframes for task T-060b. Features full-bleed viewport capture layout with 72 dp circular shutter, 56 dp thumb-reachable gallery picker, expandable disclaimer strip (F-08), multi-state capture handling (idle, permission denied, photo selected, analyzing), landscape orientation (892×412 dp), and strict safety compliance (no "diagnosis" or "cure"; zero treatment advice in uncertain state per rule D-11; dataset credit restricted per D-29).
